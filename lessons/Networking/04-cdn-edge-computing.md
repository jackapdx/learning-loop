## 📖 คำอธิบาย (Explain)

### 1. CDN (Content Delivery Network) คืออะไร?

คือเครือข่ายของเซิร์ฟเวอร์ที่กระจายตัวอยู่ทั่วโลก ทำหน้าที่เป็น **"Global Cache"**:
-**Point of Presence (PoP):** ศูนย์ข้อมูลย่อยๆ ที่ตั้งอยู่ตามเมืองต่างๆ ทั่วโลก
-**Edge Servers:** เซิร์ฟเวอร์ที่อยู่ใกล้ผู้ใช้ที่สุด
-**Static Content:** CDN เก่งมากในการเก็บไฟล์ที่ไม่เปลี่ยนบ่อย เช่น รูปภาพ, วิดีโอ, และไฟล์ Frontend

### 2. กลไกการทำงาน (Pull vs Push)

-**Pull (นิยมที่สุด):** เมื่อ User ขอไฟล์ CDN จะเช็คว่ามีไหม ถ้าไม่มีค่อยไป"ดึง" จาก Server เรา (Origin) มาเก็บไว้
-**Push 📱:** เราเป็นฝ่าย"ส่ง" ไฟล์ไปให้ CDN ล่วงหน้า (เหมือนอัปโหลดขึ้นคลาวด์)

### 3. Edge Computing (ก้าวข้ามแค่ Cache)

ยุคใหม่เราไม่ได้แค่ฝาก"ไฟล์" แต่เราฝาก **"โค้ด"** ไปรันที่ Edge ได้ด้วย (เช่น Cloudflare Workers):
- ตรวจสอบสิทธิ์ (Auth) ที่ Edge ได้เลยไม่ต้องรอวิ่งไปถึง Backend
- ปรับขนาดรูปภาพ (Image Optimization) ตามอุปกรณ์ของผู้ใช้ที่ Edge
- ทำ A/B Testing หรือ Redirect ตามประเทศของผู้ใช้

## 🔬 ขยายความ (Extend)

### ยุทธศาสตร์การลด Latency (The Senior Way)**Anycast IP:** เทคนิคที่ทำให้ IP เดียวกันสามารถวิ่งไปหาเซิร์ฟเวอร์ที่ใกล้ที่สุดได้โดยอัตโนมัติในระดับ Network 📡**Tiered Caching:** แทนที่จะให้ Edge Server ทุกตัววิ่งกลับมาหาเรา (Origin) เรามี"Regional Cache" ขั้นกลางเพื่อลดโหลดของ Origin **Purging Strategies:** เมื่อเราอัปเดตข่าวใหม่ เราต้องสั่ง"ล้างแคช" (Purge) ที่ CDN ทันทีเพื่อให้ผู้ใช้เห็นข้อมูลใหม่ (ระวัง! การ Purge บ่อยเกินไปจะทำให้โหลดวิ่งเข้า Origin หนักมาก)

### ตัวอย่างการประหยัดต้นทุน

หากคุณมี Traffic 1TB ต่อเดือน:
- โหลดจาก Origin ตรงๆ: เสียค่า Bandwidth แพง และ Server ต้องทำงานหนัก
- โหลดผ่าน CDN: ค่า Bandwidth ถูกกว่ามาก และ Server แทบไม่ต้องทำงาน (เพราะ CDN รับหน้าแทน 90%+)

## ✅ จุดตรวจสอบ (Checkpoint)

🎯**Quick Check:**"Origin Server" ในบริบทของ CDN หมายถึงอะไร?
ข้อมูลประเภท"ยอดเงินคงเหลือในบัญชี" ควรเก็บไว้ใน CDN หรือไม่? เพราะอะไร?
อะไรคือข้อเสียหลักของการใช้ CDN?

<details>
<summary>ดูเฉลย (คลิกเพื่อเปิด)</summary>**เซิร์ฟเวอร์หลักของเรา**(ต้นทางของข้อมูล) ที่ CDN จะไปดึงข้อมูลมาเมื่อเกิด Cache Miss
**ไม่ควร** เพราะข้อมูลเปลี่ยนบ่อยมากและต้องการความแม่นยำสูงสุด (Strong Consistency ⛓️) การไปฝากไว้ที่แคชจะเสี่ยงต่อการเห็นข้อมูลเก่า **Cache Inconsistency**(ข้อมูลที่แคชเก่ากว่าที่ Origin) และ **Cost**(มีค่าใช้จ่ายเพิ่มเติมตามปริมาณการใช้งาน)

</details>
